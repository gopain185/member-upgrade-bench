# Ensemble Member Upgrade Benchmark

What a soft-voting blend gains when one member improves or a new member joins, in a latent-score simulation of an
18-class problem with balanced classes.

## Provenance and generation

Fully synthetic; no real text or competition data. Generated by `python -m upgradebench.run` from the
member-upgrade-bench repository (code MIT, embedded in the companion notebook). Seeds are fixed (`default_rng(1000 + s)`
for the replace grid and `default_rng(2000 + s)` for the add grid, s = 0..3), so the files are reproducible on the same
NumPy version.

Each member scores each class as `a * (is true class) + sqrt(rho) * S + sqrt(1 - rho) * E`, where S is shared by all
members, E is private, and both are unit Gaussians. `a` is set by numerical integration to reach a target solo accuracy.
The blend is `(1 - share) * rest + share * target`, where rest is the mean of k members of solo accuracy 0.60, scaled
to unit noise. A retrained member keeps half of its private noise variance. 36,000 rows per seed.

## Files

`replace.csv`: 384 rows, one per (k, rho, rho_t, share, gain). The target member goes from solo 0.52 to 0.52 + gain at
fixed share. `add.csv`: 576 rows, one per (k, rho, rho_t, share, solo). A new member of the given solo accuracy joins,
against the rest alone. All values are means over 4 seeds.

| column | file | meaning |
| --- | --- | --- |
| k | both | number of other members |
| rho | both | their shared-noise share |
| rho_t | both | target's rho: `same`, or `lower` (half of rho) |
| share | both | target's share of the blend weight |
| gain, d_solo | replace | intended and realised solo gain |
| solo_flip | replace | share of rows where old and new member differ in correctness |
| blend_before, blend_after | replace | blend accuracy with the old and the new member |
| retention | replace | d_blend / d_solo |
| best_share_old, best_share_new, d_best | replace | best share on a 0-0.8 grid for each member, and the gain between those best blends |
| solo | add | the new member's solo accuracy |
| blend_after, best_share, d_best | add | blend accuracy with it; best share; gain at the best share over the rest alone |
| rest_acc | both | accuracy of the rest of the blend alone |
| d_blend | both | change in blend accuracy |
| d_blend_sd | both | sd of d_blend over the 4 seeds |
| flip | both | share of rows where the two blends differ in correctness |
| sd_public, z_public | both | paired sd of the change on 1,200 public rows, and d_blend / sd |
| rows_needed | both | rows for 80% power at two-sided 5%: 2.8^2 * flip / d_blend^2 (averaged over seeds, so unstable when d_blend is near 0) |

## Intended use

An expectation for how much a single-member improvement should move a blend, and how many rows it takes to see it.
Teaching material on blending and leaderboard noise.

## Known limitations

- Gaussian, exchangeable errors: real errors concentrate on class pairs and prompts, and real members are not equal.
- The other members' accuracy and the replaced member's accuracy are fixed (0.60 and 0.52).
- On one real blend (see the notebook), the observed public changes were below this model's expectation by 1.4 to 2.2 sd.
  Do not treat the expectation as a guarantee.
- Best shares are chosen on the same rows they are scored on. With 36,000 rows the optimism is small, but d_best is not
  an out-of-sample figure.
